# Carro CG — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Projeto Unity 2D que roda sozinho em Play Mode e produz uma animação de ~2 min (carro rasterizado → pista Bézier → percurso → volta espelhada), gravável com o Unity Recorder.

**Architecture:** Algoritmos da disciplina em funções puras (`Raster.cs`), testadas em EditMode. MonoBehaviours finos (`PixelCanvas`, `BezierPath`, `CarFollower`) só animam o resultado dessas funções; `Director` encadeia tudo numa coroutine com durações no Inspector. `Anim.Durante` é o único helper de tempo, usado por todos.

**Tech Stack:** Unity 6 LTS (6000.x), C# 9, Built-In Render Pipeline 2D, Unity Test Framework (NUnit), Unity Recorder.

**Spec:** `docs/superpowers/specs/2026-09-30-carro-cg-design.md`

## Global Constraints

- Unity 6 LTS (6000.x), template "2D (Built-In Render Pipeline)", projeto em `TrabFinal/CarroCG`.
- Bresenham, scanline e Bézier implementados à mão em `Raster.cs`; nada de APIs prontas para isso.
- Carro = polígonos próprios rasterizados numa `Texture2D` com `FilterMode.Point`; cenário = sprites pixel art prontos.
- Sem texto/legendas na tela.
- Gravação: Unity Recorder, MP4 1920×1080, 60 fps.
- Todas as durações das fases expostas no Inspector do `Director`.

## Review Focus

1. **Carro de cabeça para baixo na volta** — após `Espelhar()`, o carro deve continuar com o teto para cima e a frente apontando para a esquerda. Teste: `CarFollowerTests.Volta_EspelhadoNaoFicaDeCabecaParaBaixo` (Task 4).
2. **Vértice caindo exatamente numa scanline** (contado duas vezes → linha vazia no meio do polígono). Teste: `RasterTests.Scanline_VerticeNaLinha_NaoDuplica` com losango (Task 1).
3. **Polígono côncavo** (a lataria do carro é côncava) — deve gerar dois spans na mesma linha, com o vão vazio. Teste: `RasterTests.Scanline_Concavo_U` (Task 1).
4. **Polígono editado no Inspector com vértice fora da textura ou com < 3 vértices** — não pode lançar exceção; pixels fora são ignorados. Testes: `RasterTests.Scanline_Degenerado_Vazio` (Task 1) e `PixelCanvasTests.ForaDaTextura_NaoLancaEPreencheDentro` (Task 2).
5. **Pontos de controle coincidentes (P1 == P0)** → tangente nula no início; o carro deve manter o último ângulo, não girar para 0°. Teste: `CarFollowerTests.TangenteNula_MantemUltimoAngulo` (Task 4).

```csharp
using System.Collections.Generic;
using System.Linq;
using UnityEngine;

// Algoritmos da disciplina, sem dependência de cena: fáceis de testar e de citar no relatório.
public static class Raster
{
    // Bresenham generalizado para todos os octantes (só inteiros). Inclui os dois extremos.
    public static IEnumerable<Vector2Int> Line(Vector2Int a, Vector2Int b)
    {
        int x = a.x, y = a.y;
        int dx = Mathf.Abs(b.x - a.x), sx = a.x < b.x ? 1 : -1;
        int dy = -Mathf.Abs(b.y - a.y), sy = a.y < b.y ? 1 : -1;
        int err = dx + dy;
        while (true)
        {
            yield return new Vector2Int(x, y);
            if (x == b.x && y == b.y) yield break;
            int e2 = 2 * err;
            if (e2 >= dy) { err += dy; x += sx; }
            if (e2 <= dx) { err += dx; y += sy; }
        }
    }

    // Preenchimento por scanline: para cada linha y, intersecta com as arestas, ordena e pinta entre pares.
    // Cada aresta cobre [yMin, yMax) para que um vértice compartilhado não seja contado duas vezes.
    public static IEnumerable<(int y, int xStart, int xEnd)> ScanlineSpans(Vector2Int[] poly)
    {
        if (poly == null || poly.Length < 3) yield break;
        int yMin = poly.Min(p => p.y), yMax = poly.Max(p => p.y);
        var xs = new List<float>();
        for (int y = yMin; y < yMax; y++)
        {
            xs.Clear();
            for (int i = 0; i < poly.Length; i++)
            {
                Vector2Int a = poly[i], b = poly[(i + 1) % poly.Length];
                if (a.y == b.y) continue;                                   // aresta horizontal
                if (y < Mathf.Min(a.y, b.y) || y >= Mathf.Max(a.y, b.y)) continue;
                xs.Add(a.x + (float)(y - a.y) * (b.x - a.x) / (b.y - a.y));
            }
            xs.Sort();
            for (int i = 0; i + 1 < xs.Count; i += 2)
            {
                int x0 = Mathf.CeilToInt(xs[i]), x1 = Mathf.CeilToInt(xs[i + 1]) - 1;
                if (x0 <= x1) yield return (y, x0, x1);
            }
        }
    }

    // Bézier cúbica na forma de Bernstein.
    public static Vector2 BezierPoint(Vector2 p0, Vector2 p1, Vector2 p2, Vector2 p3, float t)
    {
        float u = 1 - t;
        return u * u * u * p0 + 3 * u * u * t * p1 + 3 * u * t * t * p2 + t * t * t * p3;
    }

    // Derivada da cúbica: direção do movimento em t.
    public static Vector2 BezierTangent(Vector2 p0, Vector2 p1, Vector2 p2, Vector2 p3, float t)
    {
        float u = 1 - t;
        return 3 * u * u * (p1 - p0) + 6 * u * t * (p2 - p1) + 3 * t * t * (p3 - p2);
    }
}
```

```csharp
using System.Collections;
using UnityEngine;

public static class Anim
{
    // Chama f(k) a cada frame com k indo de 0 a 1 ao longo de 'duracao' segundos. Sempre termina em f(1).
    public static IEnumerator Durante(float duracao, System.Action<float> f)
    {
        float t0 = Time.time, k;
        do
        {
            k = duracao <= 0 ? 1 : Mathf.Clamp01((Time.time - t0) / duracao);
            f(k);
            yield return null;
        } while (k < 1);
    }
}
```

`CarroCG/Assets/Scripts/PixelCanvas.cs`:
```csharp
using System.Collections;
using System.Collections.Generic;
using System.Linq;
using UnityEngine;

// Textura de baixa resolução onde o carro é rasterizado (contorno) e preenchido (scanline) aos poucos.
[RequireComponent(typeof(SpriteRenderer))]
public class PixelCanvas : MonoBehaviour
{
    [System.Serializable]
    public class Poly { public string nome; public Vector2Int[] vertices; public Color cor = Color.red; }

    public int largura = 48, altura = 24;
    public int pixelsPorUnidade = 16;
    public Color corContorno = new Color(0.08f, 0.08f, 0.12f);
    public Color corGrade = new Color(1, 1, 1, 0.15f);
    public Poly[] poligonos = CarroPadrao();

    Texture2D tex;
    bool[] contorno;
    SpriteRenderer grade;

    public Texture2D Textura => tex;

    void Awake() => Inicializar();

    public void Inicializar()
    {
        tex = new Texture2D(largura, altura, TextureFormat.RGBA32, false)
            { filterMode = FilterMode.Point, wrapMode = TextureWrapMode.Clamp };
        tex.SetPixels32(new Color32[largura * altura]);   // tudo transparente
        tex.Apply();
        contorno = new bool[largura * altura];
        var pivo = new Vector2(0.5f, 2f / altura);          // base das rodas: o carro "anda" sobre a pista
        GetComponent<SpriteRenderer>().sprite =
            Sprite.Create(tex, new Rect(0, 0, largura, altura), pivo, pixelsPorUnidade);
        CriarGrade(pivo);
    }

    // Grade de "papel quadriculado": 8 texels por pixel do carro, mesma área na cena.
    void CriarGrade(Vector2 pivo)
    {
        const int k = 8;
        var g = new Texture2D(largura * k, altura * k, TextureFormat.RGBA32, false) { filterMode = FilterMode.Point };
        var px = new Color[g.width * g.height];
        for (int y = 0; y < g.height; y++)
            for (int x = 0; x < g.width; x++)
                px[y * g.width + x] = (x % k == 0 || y % k == 0) ? corGrade : Color.clear;
        g.SetPixels(px);
        g.Apply();
        if (grade == null)
        {
            grade = new GameObject("Grade").AddComponent<SpriteRenderer>();
            grade.transform.SetParent(transform, false);
        }
        grade.sprite = Sprite.Create(g, new Rect(0, 0, g.width, g.height), pivo, pixelsPorUnidade * k);
        grade.sortingOrder = GetComponent<SpriteRenderer>().sortingOrder + 1;
    }

    public void MostrarGrade(bool visivel) => grade.enabled = visivel;

    bool Dentro(int x, int y) => x >= 0 && y >= 0 && x < largura && y < altura;

    // Rasterização: cada pixel de cada aresta (Bresenham) é um passo da animação.
    public IEnumerator DesenharContornos(float duracao)
    {
        var passos = new List<System.Action>();
        foreach (var p in poligonos)
            for (int i = 0; i < p.vertices.Length; i++)
                foreach (var px in Raster.Line(p.vertices[i], p.vertices[(i + 1) % p.vertices.Length]))
                    if (Dentro(px.x, px.y))
                        passos.Add(() =>
                        {
                            contorno[px.y * largura + px.x] = true;
                            tex.SetPixel(px.x, px.y, corContorno);
                        });
        return Executar(passos, duracao);
    }

    // Preenchimento: cada linha de scanline de cada polígono é um passo. Não pinta por cima do contorno.
    public IEnumerator Preencher(float duracao)
    {
        var passos = new List<System.Action>();
        foreach (var p in poligonos)
        {
            var cor = p.cor;
            foreach (var (y, x0, x1) in Raster.ScanlineSpans(p.vertices))
                passos.Add(() =>
                {
                    for (int x = x0; x <= x1; x++)
                        if (Dentro(x, y) && !contorno[y * largura + x]) tex.SetPixel(x, y, cor);
                });
        }
        return Executar(passos, duracao);
    }

    IEnumerator Executar(List<System.Action> passos, float duracao)
    {
        int feitos = 0;
        return Anim.Durante(duracao, k =>
        {
            for (int alvo = Mathf.CeilToInt(k * passos.Count); feitos < alvo; feitos++) passos[feitos]();
            tex.Apply();
        });
    }

    static Vector2Int[] Octogono(int cx, int cy, int r) =>
        Enumerable.Range(0, 8).Select(i => new Vector2Int(
            cx + Mathf.RoundToInt(r * Mathf.Cos(i * Mathf.PI / 4)),
            cy + Mathf.RoundToInt(r * Mathf.Sin(i * Mathf.PI / 4)))).ToArray();

    // Carro visto de lado, virado para +x, em 48x24. Ordem = ordem de desenho.
    static Poly[] CarroPadrao() => new[]
    {
        new Poly { nome = "lataria", cor = new Color(0.85f, 0.15f, 0.2f), vertices = new Vector2Int[]
            { new(2, 6), new(46, 6), new(46, 12), new(40, 14), new(34, 14), new(28, 20), new(14, 20), new(9, 14), new(2, 13) } },
        new Poly { nome = "janela traseira", cor = new Color(0.6f, 0.85f, 1f), vertices = new Vector2Int[]
```

```csharp
using System.Collections;
using UnityEngine;

// Pista = uma Bézier cúbica. A estrada é desenhada aos poucos; as linhas-guia mostram o polígono de controle.
[RequireComponent(typeof(LineRenderer))]
public class BezierPath : MonoBehaviour
{
    public Transform p0, p1, p2, p3;
    public LineRenderer guias;
    public int resolucao = 100;

    LineRenderer estrada;

    public Vector2 Point(float t) =>
        Raster.BezierPoint(p0.position, p1.position, p2.position, p3.position, Mathf.Clamp01(t));

    public Vector2 Tangent(float t) =>
        Raster.BezierTangent(p0.position, p1.position, p2.position, p3.position, Mathf.Clamp01(t));

    void Awake()
    {
        estrada = GetComponent<LineRenderer>();
        estrada.positionCount = 0;
        MostrarGuias(false);
    }

    public IEnumerator Revelar(float duracao)
    {
        MostrarGuias(true);
        return Anim.Durante(duracao, k =>
        {
            int n = Mathf.RoundToInt(k * resolucao);
            estrada.positionCount = n + 1;
            for (int i = 0; i <= n; i++) estrada.SetPosition(i, Point(i / (float)resolucao));
        });
    }

    public void EsconderGuias() => MostrarGuias(false);

    void MostrarGuias(bool visivel)
    {
        guias.positionCount = visivel ? 4 : 0;
        if (visivel) guias.SetPositions(new[] { p0.position, p1.position, p2.position, p3.position });
        foreach (var p in new[] { p0, p1, p2, p3 })
            if (p.TryGetComponent(out SpriteRenderer r)) r.enabled = visivel;
    }

    void OnDrawGizmos()
    {
        if (!p0 || !p1 || !p2 || !p3) return;
        Gizmos.color = Color.yellow;
        for (int i = 0; i < 40; i++) Gizmos.DrawLine(Point(i / 40f), Point((i + 1) / 40f));
        Gizmos.color = Color.gray;
        Gizmos.DrawLine(p0.position, p1.position);
        Gizmos.DrawLine(p2.position, p3.position);
    }
}
```

```csharp
using System.Collections;
using UnityEngine;

// Move o carro sobre a pista: translação (posição), rotação (tangente) e espelhamento (escala -1 em x).
public class CarFollower : MonoBehaviour
{
    public BezierPath pista;

    float angulo;

    public void Posicionar(float t)
    {
        transform.position = pista.Point(t);                        // translação
        Vector2 d = pista.Tangent(t);
        if (d.sqrMagnitude > 1e-6f) angulo = Mathf.Atan2(d.y, d.x) * Mathf.Rad2Deg;
        transform.rotation = Quaternion.Euler(0, 0, angulo);        // rotação
    }

    // ponytail: velocidade por t, não por comprimento de arco; reparametrizar se a variação incomodar no vídeo.
    public IEnumerator Percorrer(float de, float ate, float duracao) =>
        Anim.Durante(duracao, k => Posicionar(Mathf.Lerp(de, ate, k)));

    public void Espelhar()                                          // espelhamento
    {
        var s = transform.localScale;
        s.x *= -1;
        transform.localScale = s;
    }
}
```

### Task 5: Director.cs — sequência do vídeo

**Files:**

**Interfaces:**
- Consumes: `PixelCanvas.DesenharContornos/Preencher/MostrarGrade` (Task 2), `BezierPath.Revelar/EsconderGuias` (Task 3), `CarFollower.Posicionar/Percorrer/Espelhar` (Task 4), `Anim.Durante` (Task 2).
- Produces: `Director` (fica na Main Camera) com referências e durações no Inspector.

Sem teste automatizado: é só sequenciamento; a verificação é assistir em Play Mode (Task 6).

- [ ] **Step 1: implementar**

`CarroCG/Assets/Scripts/Director.cs`:
```csharp
using System.Collections;
using UnityEngine;

// Roteiro do vídeo. Ajuste as durações no Inspector para casar com a narração.
[RequireComponent(typeof(Camera))]
public class Director : MonoBehaviour
{
    public PixelCanvas canvas;
    public CarFollower carro;
    public BezierPath pista;
    public GameObject cenario;
    public SpriteRenderer fade;

    [Header("Câmera")]
    public float zoomMontagem = 1.1f;
    public float zoomGeral = 6f;
    public Vector3 posGeral = new Vector3(0, 0, -10);

    [Header("Durações (s)")]
    public float abertura = 10;
    public float contorno = 25;
    public float preenchimento = 20;
    public float transicao = 10;
    public float tracarPista = 8;
    public float mostrarGuias = 2;
    public float ida = 30;
    public float volta = 10;
    public float final = 10;

    IEnumerator Start()
    {
        var cam = GetComponent<Camera>();
        cenario.SetActive(false);
        fade.color = Color.clear;
        carro.Posicionar(0);
        var posMontagem = carro.transform.position + new Vector3(0, 0.6f, -10);
        cam.transform.position = posMontagem;
        cam.orthographicSize = zoomMontagem;

        yield return new WaitForSeconds(abertura);
        yield return canvas.DesenharContornos(contorno);        // rasterização
        yield return canvas.Preencher(preenchimento);           // preenchimento

        canvas.MostrarGrade(false);
        cenario.SetActive(true);
        yield return Anim.Durante(transicao, k =>
        {
            k = Mathf.SmoothStep(0, 1, k);
            cam.orthographicSize = Mathf.Lerp(zoomMontagem, zoomGeral, k);
            cam.transform.position = Vector3.Lerp(posMontagem, posGeral, k);
        });

        yield return pista.Revelar(tracarPista);                // curva de Bézier
        yield return new WaitForSeconds(mostrarGuias);
        pista.EsconderGuias();

        yield return carro.Percorrer(0, 1, ida);                // translação + rotação
        carro.Espelhar();                                       // espelhamento
        yield return carro.Percorrer(1, 0, volta);

        yield return Anim.Durante(final, k => fade.color = new Color(0, 0, 0, k));
    }
}
```
